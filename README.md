# Seasons — концепт главной (редизайн)

Неофициальный концепт редизайна главной seasons-project.ru. Next.js 14 (App Router), JavaScript, CSS Modules, GSAP + ScrollTrigger, Lenis.

## Запуск на Windows

1. Установи Node.js LTS (18.17 или новее): https://nodejs.org
2. Открой папку проекта в VS Code, в терминале (Ctrl + `):

```
npm install
npm run dev
```

3. Открой http://localhost:3000. Остановить сервер: Ctrl + C.

Важно: после обновления файлов обязательно снова запусти `npm install` (появилась библиотека GSAP).

## Что на странице

- **Hero** — экран закрепляется, журнал по центру листается от прокрутки (или тяни страницу за угол). Под ним огромное слово темы номера, вокруг падают бумажные вырезки и двигаются за мышью. Кнопка-наклейка «купить номер» притягивается к курсору.
- **Актуальное** — акварель раскрывается из карточки на весь экран, дальше вертикальный скролл двигает ленту бумажных листков вбок. Листки наклоняются от скорости прокрутки. На телефоне лента листается пальцем.
- **Читать** — фраза «Хочу почитать про …», где рубрика крутится как барабан слот-машины (клик по слову) и подчёркивается карандашом. Ниже огромные заголовки списком, за курсором летит листок-превью.
- **Подвал** — синий экран, вырезки падают и остаются лежать кучей на дне. Плашка «неофициальный концепт» оставлена.
- **Меню** — круглая кнопка, меню раскрывается кругом на весь экран.
- Яблоко справа катится вниз как индикатор прокрутки, за курсором тянется линия как от карандаша и быстро исчезает, кольцо появляется только над ссылками (всё это только на мыши).

## Где что лежит

- `data/content.js` — тексты, ссылки, номера журналов, материалы блога.
- `app/globals.css` — цвета, шрифты, отступы.
- `components/` — блоки страницы, у каждого свой `.module.css`. Анимации лежат в `useEffect` каждого компонента (GSAP).
- `public/img/cut/` — бумажные вырезки (листья, яблоко, слива, ветка) с прозрачным фоном.
- `public/img/hero.jpg` — акварель для секции «Актуальное»; старый коллаж из ткани сохранён как `hero-fabric-collage.jpg`.
- `components/Magazine.*` — журнал на библиотеке page-flip, листается от скролла в Hero.
- `components/Flipbook.*`, `components/Issues.*` — старые версии (журнал с автолистанием и стопка обложек), сейчас не подключены.

## Заметки

- Для людей с включённым «уменьшением движения» в системе анимации выключены, всё показывается сразу.
- Форма рассылки ничего не отправляет: это концепт.
- Шрифты Piazzolla и Onest подключаются с Google Fonts в `app/layout.js`.
